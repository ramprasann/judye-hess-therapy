# Judye Hess, Ph.D. – Relationship Therapy

Official modern web application for **Dr. Judye Hess, Ph.D.** (California Licensed Clinical Psychologist #PSY 7468).

> Specializing in Couples Therapy, Intergenerational Family Systems, and Interpersonal Process Groups in South Berkeley, California and statewide California telehealth via Zoom.

---

## 🌟 Clinical Modalities & Pages

- **Home (`/`):** Practice overview, core therapeutic philosophy, authored book showcase, and client & peer reflections.
- **My Practice (`/my-practice`):** Relational focus, holding environment, and modalities overview.
- **About Me (`/about-me`):** Background, education, 30+ years CIIS clinical faculty leadership, and career milestones.
- **Qualifications (`/my-qualifications`):** California license credentials (`PSY 7468`), clinical competencies, and colleague endorsements.
- **Publications & Media (`/publications`):** *Core Focused Family Therapy* book showcase, downloadable research monographs (PDF), and national press citations (*The New York Times*, *Elle*, *SF Chronicle*).
- **Family Therapy (`/family-therapy`):** Adult children and parents intergenerational therapy.
- **Couples Therapy (`/couples-therapy`):** Systems-based approach and 7 common relationship challenges.
- **Group Therapy (`/group-therapy`):** Safe, supportive interpersonal growth laboratory.
- **Blog & Perspectives (`/blog`):** Clinical essays on autonomy, differentiation, and living apart together (LAT).
- **Contact & Location (`/contact-location`):** South Berkeley consulting office (Ashby BART), statewide Zoom telepractice, and confidential consultation intake form.

---

## 🛠️ Tech Stack

- **Framework:** React 18 (TypeScript)
- **Bundler & Dev Server:** Vite 5
- **Styling:** Tailwind CSS with warm luxury editorial palette
- **Icons:** Lucide React (100% SVG)
- **Forms & Validation:** React Hook Form + Zod
- **Routing:** React Router v6

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ramprasann/judye-hess-therapy.git

# Navigate into directory
cd judye-hess-therapy

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
